# 260929-01 toolgplat 数组/结构体字面量与 Board write

## 1. 需求要点

1. 队列 `write` 中数组用 `[]` 表示更清晰，如 `speed=[1.5,2,9] motor_name=[a,b,c]`（原来只接受 `speed=1.5,2,9`，写 `[1.5` 报 `Invalid value`）。
2. 含自定义结构体字段（如 `Vehicle` 的 `pos: GPSPosition`、`history: GPSPosition[3]`）时，除逐成员赋值外，支持整体赋值简写：`pos={31.2,121.5}`、`history=[{..},{..}]`。
3. BOARD 中的 tag 增加类似队列的 `write` 命令。

实施前确认的决策（Board write）：

| 问题 | 结论 |
|---|---|
| 语法 | `write <tag> <value>` 或 `write <tag> <path>=<value> ...`，path 相对于 tag |
| 部分赋值时未指定部分 | 默认保留原值（先读后改再写）；可选参数 `zero` 先清零 |
| 是否通知订阅者 | 默认 `writeb`（通知）；可选参数 `nopost` 使用 `writeb_notpost` |

## 2. 值的语法

| 形式 | 含义 |
|---|---|
| `v` | 基本类型标量 / 字符串（含空白时加双引号） |
| `[v0,v1,...]` | 数组，按顺序赋值；元素个数少于数组长度时其余元素不赋值 |
| `{m0,m1,...}` | struct，按成员声明顺序赋值；成员本身可以是 `[...]` 或 `{...}` |
| `v0,v1,...` | 不带括号的数组（兼容旧写法） |

- 括号可嵌套，如 `history=[{30.1,120.3},{30.5,120.8}]`；`[]`、`{}` 内可以有空白，如 `pos={31.2, 121.5}`。
- 字段路径 `name`、`name[i]`、`name.member`、`name[i].member` 保持不变；`name[i]` 对 struct 数组元素也可整体赋值：`history[1]={30.5,120.8}`。
- 错误提示：值个数超过数组长度 / struct 成员数；struct 字段给了非 `{...}` 的值；括号不配对。

队列示例：

```
write speed=[1.5, 2, 9] current=2.0 motor_name=[a,b,c]
write id=7 pos={31.2,121.5} history=[{30.1,120.3},{30.5,120.8}] plate=AB123
write id=7 pos.latitude=31.2 history[1]={30.5,120.8} history[2].longitude=121.5
```

## 3. Board write

```
write <tagName> [nopost] [zero] <value>
write <tagName> [nopost] [zero] <path>=<value> [<path>=<value> ...]
```

path 相对于 tag：`member`、`member.sub`、`[i]`、`[i].member`。

| tag 类型 | 示例 |
|---|---|
| 标量 | `write temperature 25.5` |
| 数组 | `write vals [1,2,3]`（其余元素不变），`write vals [4]=99` |
| 字符串（Char 数组） | `write msg "motor overheat"` |
| struct | `write v1 {7, {31.2,121.5}}`，`write v1 pos={31.2,121.5} history[1].latitude=30.5` |
| struct 数组 | `write sa [0].temperature=25 [2]={30,60,1.01,true,"Lab 1"}`，`write sa zero [{1,2},{3,4}]` |

- 流程：`readtype` 读取类型描述符 → 构造覆盖整个 tag 的 `FieldInfo` → 未指定 `zero` 时 `readb` 读出当前值 → 应用赋值 → `writeb` / `writeb_notpost`。
- `zero` 单独使用（`write sa zero`）写入全零。
- 字符串 tag 走 `writeb_string` / `writeb_string_notpost`，只接受一个值；`zero` 对其无意义。为能写入文本 "zero"/"nopost"，字符串 tag 的最后一个词总是作为值。
- struct 类型未在本地注册、或类型码不支持时拒绝写入。
- struct 数组 tag 不带下标赋成员时报错，提示 `specify an index, e.g. <tag>[0].<member>=...`（提示中的写法是队列路径形式，Board 中实际写 `[0].<member>=...`）。

## 4. 代码改动

### 4.1 `toolgplat/record_input.cpp/.h`

- `SplitTopLevel`：按顶层逗号切分，`[]`、`{}` 内的逗号不切分。
- `Unwrap`：判断整个文本是否被一对匹配的 `[]` / `{}` 包裹并取出内部（`[1],[2]` 不算被包裹）。
- `AssignField`（整个字段，数组用 `[...]` 或裸逗号列表）与 `AssignElement`（单个元素，struct 用 `{...}`）相互递归，取代原先 `Assign` 末尾的逗号切分逻辑；`Assign` 对 struct 字段在路径末尾时不再报错，改为整体赋值。
- 新增 `ApplyTagValues(tag, data, words, error)`：用单字段的包装 `StructInfo` 复用 `Assign`；以 `[` 开头或 tag 为 struct 且含 `=` 的词视为 `<path>=<value>`，否则作为整体值（只允许一个）。路径首段固定为 tag 本身，tag 名不参与 `.` 切分。

### 4.2 `toolgplat/text_util.h`

- `SplitWords`：双引号外 `[]`、`{}` 内的空白不切分。

### 4.3 `toolgplat/main.cpp`

- 新增 Board 作用域命令 `write`（`CmdBoardWrite`）及辅助函数 `ReadTagType`、`MakeTagField`、`PrintTagWriteResult`。
- 更新队列 `write` 与 Board `write` 的帮助，`open` 帮助中 Board 命令列表加入 `write`。

### 4.4 `include/higplat.h`

- 声明已存在于 `libhigplat.so` 的 `writeb_string_notpost`（此前仅 s7ioserver 自行声明）。
